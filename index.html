Sync across devices (optional)

Keeps your library identical on Mac and iPhone by storing it in the GitHub repository that hosts this app. Create a token at github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens: Repository access = only your app repo, Permissions → Contents = Read and write. Paste it here on each device (it stays in this browser only).

YouTube search connection (optional)

YouTube-wide search works out of the box through public mirrors. For a faster, more reliable direct connection, paste your own free YouTube Data API v3 key. It's stored only in this browser.

App updates

Got a new version file? Install it from here — the app uploads it to your repository itself (uses your sync token). No GitHub website needed.
